# AgroNest Frontend

Welcome to the **AgroNest Frontend** repository! This is the frontend of AgroNest, an advanced agricultural platform that integrates AI-powered **LLM features** and **disease detection** to assist farmers and agricultural experts.

## 🌱 About AgroNest
AgroNest leverages cutting-edge **LLM technology** and **machine learning models** to provide real-time agricultural insights, helping users with:
- **AI-powered agricultural assistance**
- **Crop disease detection**
- **Smart farming recommendations**

For the core <b>LLM features and disease detection models</b>, visit the backend repository:  
🔗 [AgroNest LLM-ML](https://github.com/ashuvo25/AgroNest_LLM-ML)

 🚀 Getting Started
Follow these steps to run the AgroNest frontend on your local machine:

📌 Prerequisites
Ensure you have the following installed:
- Node.js(Latest LTS recommended)
- npm (Node Package Manager)

🔧 Installation & Setup
1. Clone the repository
   ```sh
   git clone https://github.com/your-username/AgroNest_frontend.git
   cd AgroNest_frontend 
2. Install dependencies
   ```sh
   npm install 
3. Start the development server
   ```sh
   npm run dev 

The application will be running locally, usually at http://localhost:3000.

🛠 Technologies Used
- React.js – Frontend framework
- Tailwind CSS – Modern UI styling
- Vite – Fast development bundler
- Axios – API requests handling
